# RightHand - Accessibility Compliance Checker

RightHand is a web-based Accessibility Compliance Checker built for CSE4149 (Software Verification and Testing). Users submit a public website URL and receive an automated WCAG-oriented accessibility report generated by a combined analysis pipeline.

## Planned Tech Stack

| Layer | Technology |
| --- | --- |
| Backend | Node.js 18+, Express (CommonJS) |
| Accessibility Scanning | Puppeteer, axe-core via @axe-core/puppeteer, Lighthouse |
| Database | PostgreSQL 15 with pg |
| Frontend | React 18, Chart.js (react-chartjs-2), Axios, React Router |
| Testing | Jest + Supertest (backend), Jest/Vitest + React Testing Library (frontend) |
| Infrastructure | Docker, Docker Compose, Nginx, GitHub Actions, GHCR |
